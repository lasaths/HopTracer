# Security Policy

## Supported Versions

Security fixes are applied to the latest code on `main` and the latest tagged release.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` branch | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report privately using GitHub Security Advisories:

`https://github.com/lasaths/HopTracer/security/advisories/new`

Include:

1. A clear description of the issue.
2. Steps to reproduce.
3. Impact assessment.
4. Any proof-of-concept or logs.

Expected response:

1. Initial acknowledgment within 7 days.
2. Triage and severity assessment after reproduction.
3. Coordinated disclosure once a fix is available.
