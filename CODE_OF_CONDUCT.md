# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, inclusive, and harassment-free experience for everyone participating in this project.

## Expected Behavior

1. Be respectful and constructive.
2. Assume good intent, and discuss ideas with technical clarity.
3. Accept feedback gracefully.
4. Focus on what is best for the project and community.

## Unacceptable Behavior

1. Harassment, discrimination, or abusive language.
2. Personal attacks, trolling, or intimidation.
3. Publishing private information without consent.
4. Any conduct that is inappropriate in a professional environment.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct and may remove, edit, or reject contributions or comments that violate it.

## Reporting

To report unacceptable behavior, open a private maintainer contact through GitHub:

`https://github.com/lasaths/HopTracer/issues/new`

Please include relevant context and links/screenshots.
